Diseño automatizaciones con IA generativa e integraciones sobre WhatsApp (Meta Cloud API), y construyo sitios de alto rendimiento para clientes reales.

**Aurora**, una recepcionista virtual de WhatsApp para consultorios, funciona como demostración funcional en mi propio VPS, con un consultorio ficticio. El **Sistema Anti No-Shows** funciona como demo pública en mi VPS. Ninguno tiene todavía clínicas clientes, y lo digo de entrada porque es parte del criterio con el que trabajo: declarar qué está probado y qué falta.

Antes de esto, 15 años en instrumentación quirúrgica. Esa misma precisión se traslada al código: protocolo, trazabilidad y control de errores.

## Especialidades técnicas

**IA aplicada y automatización**

- Clasificación de lenguaje natural con Gemini API integrada a flujos de WhatsApp (demostraciones funcionales)
- Orquestación de workflows con n8n: triggers de tiempo, webhooks, lógica condicional
- Bots conversacionales con estado en Node.js cuando la lógica es demasiado compleja para un canvas visual
- Demos desplegadas en VPS propio (Contabo) con PM2, Nginx y SSL

**Performance y estructura técnica**

- Core Web Vitals y Lighthouse 90–100, medidos con PageSpeed Insights
- Schema markup: `Physician`, `MedicalBusiness`, `LocalBusiness`, `FAQPage`, `AggregateRating`
- HTML/CSS/JS puro cuando el proyecto lo permite, sin dependencias innecesarias
