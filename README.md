Construyo sistemas que combinan IA generativa con automatización real — no demos, no prototipos: código corriendo en producción, atendiendo gente de verdad.

Los últimos meses diseñé y sostengo dos sistemas médicos en producción: una recepcionista virtual que clasifica consultas de pacientes por WhatsApp con IA, y un sistema de reducción de ausencias que corre solo, sin intervención manual. Ambos documentados y con código público más abajo.

Antes de esto, 15 años en instrumentación quirúrgica. Esa misma precisión se traslada al código: lo que no suma, se saca.

## Especialidades técnicas

**IA aplicada y automatización**

- Clasificación de lenguaje natural con LLMs (Claude API, Gemini API) integrada a flujos de negocio reales
- Orquestación de workflows con n8n — triggers de tiempo, webhooks, lógica condicional
- Arquitectura de bots conversacionales con estado (Node.js) cuando la lógica es demasiado compleja para un canvas visual
- Bots corriendo en VPS propio (Contabo), con PM2, Nginx y SSL en producción

**Performance y estructura técnica**

- Core Web Vitals — LCP <1s, CLS 0, TBT 0ms
- Lighthouse 90-100 documentado con captura en cada entrega
- Schema markup: `Physician`, `MedicalBusiness`, `LocalBusiness`, `FAQPage`, `AggregateRating`
- HTML/CSS/JS puro cuando el proyecto lo permite — sin dependencias innecesarias
